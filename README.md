# Парсер судебных решений

Проект для парсинга судебных решений из текстовых файлов и сохранения данных в базу данных.

## 📋 Описание проекта

Проект разработан для учебных целей и включает:
- Парсинг текстовых файлов с судебными решениями
- Извлечение структурированных данных (номер решения, дата, номер дела, суд, судья)
- Сохранение данных в базу данных (PostgreSQL или ClickHouse)
- Модульную структуру с использованием ООП
- Тестирование всех компонентов

## 🏗️ Структура проекта

```
.

```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements_parser.txt
```

### 2. Подготовка данных

Поместите текстовые файлы с судебными решениями в папку `parsed_decisions/`.

Пример формата файла:
```
АРБИТРАЖНЫЙ СУД ГОРОДА МОСКВЫ

РЕШЕНИЕ
от 25.05.2024
по делу № А40-98765/2024

Судья: Смирнов Алексей Владимирович

... текст решения ...
```

### 3. Запуск парсера

```bash
python main_parser.py
```

Или выберите опцию "Парсинг файлов" в меню.

### 4. Запуск тестов

```bash
# Все тесты
python run_tests.py

# Только тесты парсера
python test_parser.py

# Только тесты базы данных
python test_database.py

# Демонстрация работы
python run_tests.py demo
```

## 🔧 Настройка базы данных

### PostgreSQL

1. Установите PostgreSQL
2. Создайте базу данных:
```sql
CREATE DATABASE court_decisions;
```

3. Настройте подключение в `database/db_manager.py`:
```python
db_manager = DatabaseManager(
    db_type='postgresql',
    host='localhost',
    port=5432,
    database='court_decisions',
    username='postgres',
    password='your_password'
)
```

### ClickHouse (опционально)

1. Установите ClickHouse
2. Установите драйвер:
```bash
pip install clickhouse-sqlalchemy
```

3. Настройте подключение в `database/db_manager.py`

## 📊 Извлекаемые данные

Парсер извлекает следующие данные из текстовых файлов:

1. **Номер решения** - например, "А40-12345/2023"
2. **Дата решения** - в формате DD.MM.YYYY
3. **Номер дела** - например, "А40-12345/2023"
4. **Место принятия решения** - например, "Арбитражный суд города Москвы"
5. **Судья** - например, "Иванов И.И."
6. **Полный текст решения**

## 🔮 Планы развития

1. **Веб-интерфейс** - FastAPI для управления через браузер
